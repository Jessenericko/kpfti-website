Petunjuk Pengisian Data Kerja Praktik (KP)

  • Isilah data Kerja Praktik (KP) kelompok Anda dengan benar dan lengkap.
  • Pada kolom Tempat KP, sistem akan menampilkan daftar perusahaan yang pernah didaftarkan.
  • Pilih salah satu perusahaan dari daftar tersebut untuk mengisi alamat dan informasi kontak perusahaan secara otomatis, apabila data perusahaan sudah tersedia di sistem.

Ketentuan Unggah File

  • File yang dapat diunggah harus berformat gambar (image), PDF, atau arsip terkompresi (ZIP, 7Z, atau TAR).
  • File sinopsis dan laporan sebelum sidang wajib berformat PDF.
  • Ukuran maksimum total file yang diunggah adalah kurang dari 20 MB.
  • Jika total ukuran file melebihi batas tersebut, silakan unggah file satu per satu.

  3. Pilih printer dengan nama PDF.
  4. Upload dengan file yang baru (yang muncul setelah di print).
